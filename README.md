# Portafolio

Sitio personal hecho con Vue 3, Vite y Tailwind CSS.

## Desarrollo

```bash
npm install
npm run dev
```

El contenido (perfil, proyectos y tecnologías) está en `src/data/profile.js` y las capturas en `src/assets/proyectos/<sistema>/`.

## Compilación

```bash
npm run build
```

Genera el sitio estático en `dist/`.
